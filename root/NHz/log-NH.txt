+   Steps to Create a Google Cloud VM

    Sign in and Select Project: 
        Open the Google Cloud Console and select or 
        create your active project (ensure billing is linked).
    
    Navigate to Compute Engine: 
        Use the left-side navigation menu, 
            go to Compute Engine, and click on VM instances.
    
    Create Instance: 
        Click the Create instance button at the top of the page.
    
    Configure Basics: 
        Assign a Name to your virtual machine, and select your preferred Region and Zone.
    
    Choose Machine Type: 
        Select a machine configuration 
        (such as General purpose E2 or N1 series) depending on your required CPU and memory workloads.
        
    Select Boot Disk: 
        Choose your operating system image 
        (like Ubuntu, Debian, or Windows Server) and adjust the storage size if needed.
    
    Configure Firewalls: 
        Check options to allow HTTP/HTTPS traffic if you plan 
        to host a web server.
        
    Launch and Connect: 
        Click Create, 
            wait a moment for deployment, 
        and click the SSH button next to 
            your instance name to connect directly inside your browser. [1]

+   TPU 
    A TPU (Tensor Processing Unit) is a custom microchip designed by Google specifically to accelerate artificial intelligence and machine learning workloads.  
    Unlike general-purpose computer chips (CPUs) 
        or graphics cards (GPUs), 
    a TPU is an ASIC (Application-Specific Integrated Circuit). 
    It was built from the ground up for the 
    specific math operations that power deep learning.  


+   Tensor 
    Ein Tensor ist der mathematische und informatikbezogene Oberbegriff für 
        Daten-Container, 
        die Zahlen in einer bestimmten Dimensionalität anordnen.  
    Die leichteste Metapher ist ein Baukastensystem von Dimensionalitäten: 
        Ein Skalar ist ein einzelner Punkt, 
        ein Vektor eine Reihe von Punkten, 
        eine Matrix eine Fläche – 
    und ein Tensor verallgemeinert dieses Konzept auf beliebig viele Dimensionen.
