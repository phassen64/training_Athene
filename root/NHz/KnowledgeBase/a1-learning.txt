$   fault vs error vs failure

    While often used interchangeably in casual 
        conversation, 
        fault and error represent distinct 
        stages in a cause-and-effect chain 
    within systems, software, and engineering:

    •   fault 
        definition:    
            The underlying cause, defect, 
                flaw, or mistake in the system or code.
        key difference:    
            Cause (Static / Latent)
        example:
            A programmer writes '>' instead of '>=' 
            in a conditional loop.
    
    •   error    
        definition:
            The incorrect internal state resulting 
                from a fault during execution.
        key difference:
            Manifestation (Dynamic)
        example:
            A variable holds a value of 10 
                when it should be 11.

    •   failure 
        definition:
            The observable incorrect behavior 
                visible to the end user or external system.
        key difference:
            Effect (External Result)
        example:
            The application crashes or produces an 
                incorrect final total on screen.

=== m:  [1.6]   Infrastructure as Code (IaC) Basics with Terraform

+   What is IaC ?

    01  IAC manages infrastructure thorough code, 
        not manual    processes            
   
    02  developers define servers. networks, storage 
        and cloud seources 

    03  using configuration files are version-controlled,
        resusable and automated 
        
        
+   How IaC works ?

    1.  IaC automates infrastructure through machine-readable code    
    2.  it enbales scalability, repeatable and faster deployment with 
        less manual effort
        
+   IaC workflow 
    step1:  developer define infrastructure using 
                scripts, templates or policies 
    step2:  the files are stored in a version control system 
                for collaboration, version tracking, auditing and rollback
    step3:  tools like 
            •   Terraform 
            •   Ansible 
            •   Chef
            •   Puppet
            •   AWS CloudFormation
    step4-6:
            •   servers 
            •   databases 
            •   storage 
            •   networks
            •   cloud services 
            actions:
                create & update & remove

+   example 
    Terraform
        provider "aws" {        *   welcher CSP 
        region = "us-west-2"    *   welcher region 
    }
    resource "aws_instance" "example" {
        ami           = "ami-0c55b159cbfafe1f0"     *   instance id 
        instance_type = "t2.micro"      *   welche provisioning model
        tags = {
            Name = "IaC-Managed-Instance"
        }
    }
               

+   Benefits of IaC 
    ... delivers consistent environments
    ... encourages reusable modules 
    ... simplifies disaster recovery by recreating infrastructure from code
    
+   Approaches of IaC 
    1.  declarative 
        •   Terraform 
        •   AWS CloudFoundation 
        •   Kubernet YAML 
        focus : "what the infrastructure should look like"
        
    2.  imperative
        •   Ansible 
        •   bash scrips 
        •   powershell scripts
        focus : "how to achieve the desired state"

    •   Versionskontrolle: 
        Infrastruktur-Code wird wie Anwendungscode in

=== m:  [2.2]   Neural Networks and Deep Learning Fundamentals


+   Key Characteristics of Neural Networks: 
    •   Learning from Data: 
        Improves performance as more data becomes available 
    •   Non-linear Modeling: 
        Can capture complex relationships between variables 
    •   Adaptability: 
        Adjusts to changing project conditions 
    •   Generalization: 
        Applies learned patterns to new, unseen data

+   Key Elements in Neural Networks: 

    •   Weights & Biases: 
        Control how inputs are transformed; 
            updated during training to  improve accuracy.  

    •   Activation Functions: 
            Introduce non-linearity and determine neuron outputs.  

    •   Loss Function: 
            Measures prediction error between actual 
                and predicted values.  

    •   Optimization Algorithms: 
        Adjust parameters (e.g., using gradient descent) to minimize error. 

    
+   Neural Networks (ANNs) process information in 
    a structured, layer-by-layer manner inspired 
        by the human brain.
    
    
    
+   Key Characteristics of Deep Learning  (DL)  

    •   Uses multiple hidden layers for advanced feature extraction.  
    •   Learns directly from large amounts of raw data.  
    •   Reduces the need for manual feature engineering.  
    •   Delivers high accuracy for complex pattern recognition tasks.  
    •   Requires substantial computational power and large datasets.

    <   Note:   modern voice assistance such as Siri, Google Assistant
            and Alexa rely heavily on deep learnin models
            
+   Common Deep Learning Models                
    •   Convolutional Neural Networks (CNNs)    
    •   Recurrent Neural Networks (RNNs)    
    •   Transformers 
    •   Generative Adversarial Networks (GANs) 
    •   Autoencoders

+   Benefits of Deep Learning: 
    Deep learning offers significant advantages in solving 
        complex problems by automatically 
    learning patterns from large datasets. 
    Its ability to deliver high accuracy, scalability,

=== m:  [2.5]   Mathematics for AI

+   Uses of Linear Algebra in AI:

    •   Data Representation
        Represents datasets as vectors and matrices for efficient storage and processing.

    •   Machine Learning Models: 
        Forms the mathematical foundation of algorithms such as 
        Linear Regression, Logistic Regression, and Support Vector Machines.

    •   Neural Networks: 
        Uses matrix operations to compute inputs, weights, 
        biases, and outputs in deep learning models.

    •   Image Processing and Computer Vision: 
        Represents images as matrices of pixel values for tasks 
        such as object detection and facial recognition.

    •   Natural Language Processing (NLP): 
        Converts words, sentences, 
            and documents into numerical vectors for language understanding.

    •   Dimensionality Reduction: 
        Reduces data complexity while preserving important
            information using techniques such as 
            Principal Component Analysis (PCA).

+   Key Components of Linear Algebra

    •   Scalars
        Single numerical values used to represent 
            quantities (e.g., 5, 10.5, - 3).

    •   Vectors
        Ordered collections of numbers representing data points, 
            features, or directions.

    •   Matrices
        Rectangular arrays of numbers arranged in rows and columns, 
            used to store and process data.

    •   Tensors
        Multi-dimensional extensions of matrices used 
            in deep learning and AI applications.

    •   Matrix Operations
        Mathematical operations such as 
        addition, subtraction, multiplication, 
            and transpose performed on matrices.

    •   Determinants
        Special values calculated from square matrices 
            that indicate properties such as invertibility.

    •   Inverse Matrices
        Matrices that reverse the effect of matrix multiplication and 
        help solve systems of equations.

    •   Eigenvalues and Eigenvectors
        Important concepts used to identify patterns, 
            directions, and data variance in datasets.

    •   Linear Transformations
        Operations that change the position, size, 
            or orientation of vectors while preserving linear relationships.

    •   Systems of Linear Equations
        Sets of equations solved simultaneously using matrix methods.

+   Die Grundgleichung (Eigenwertproblem)
    Wendet man die Matrix A auf einen von 
        Null verschiedenen Vektor v (den Eigenvektor) an, 
        ändert sich bei einem echten Eigenvektor nicht die Richtung, 
        sondern er wird lediglich mit dem Faktor λ skaliert:
    
    A * v = λ * v
        
        A:  Quadratische Matrix 
        v:  Eigenvektor
        λ:  Eigenwert
    url:    https://studyflix.de/mathematik/eigenwert-1635
    
+   Inverse Matrix 
    Wenn du eine Zahl $a$ mit ihrem Kehrwert 
        A * A **-1 = A**-1 * A = I multiplizierst, erhältst du 1. 
    Bei Matrizen ist das Prinzip analog: 
        Multiplizierst du eine quadratische Matrix $A$ mit ihrer inversen Matrix $A^{-1}$, 
    erhältst du die Einheitsmatrix $I$ (die Matrix, 
    die auf der Hauptdiagonale Einsen und sonst nur Nullen hat).
    $$A \cdot A^{-1} = A^{-1} \cdot A = I$$

+   Data is the foundation of

--- s:  [2.6.1] Data Preprocessing

+   Data Preprocessing
    ~ is the process of cleaning and transforming raw data into 
        a structured format suitable for analysis 
        and machine learning algorithms. 
    High-quality data leads to more accurate and reliable models.


+   Objectives of Data Preprocessing:
    *   Improve data quality and consistency.
    *   Handle missing or incorrect values.
    *   Remove noise and redundancy.
    *   Convert data into machine-readable formats.
    *   Enhance model performance and accuracy.

+   Key Data Preprocessing Techniques:
    
    •   Data Cleaning
        Removes errors, duplicate records, and inconsistencies.

    •   Handling Missing Values
        Replaces or removes missing data using statistical methods.

    •   Data Transformation
        Converts data into suitable formats for analysis.

    •   Data Normalization
        Scales numerical values to a common range.

    •   Data Standardization
        Adjusts data to have a mean of 0 and standard deviation of 1.
        
    •   Encoding Categorical Data
        Converts text categories into numerical values.

    •   Feature Selection
        Identifies the most relevant variables for analysis.

    •   Feature Engineering
        Creates new features from existing data to improve model 
            performance.

--- s:  [2.6.2] Data Exploration (Exploratory Data Analysis - EDA)

    Data exploration{"erforschen"} is the process of examining datasets 
        to understand their characteristics, discover patterns, 
        detect anomalies, 
        and identify relationships among variables.

+   Objectives of Data Exploration:
    *   Understand data distribution.
    *   Detect outliers and anomalies.
    *   Identify trends and patterns.
    *   Discover relationships between variables.
    *   Generate hypotheses for further analysis.

+   Common EDA Activities:

    Exploratory Data Analysis (EDA) 
        involves examining and summarizing data to understand 
        its characteristics, identify patterns, 
        and detect potential issues before 
        building analytical or machine learning models. 
    
    The following are some of the most common EDA activities:

    •   Summary Statistics
        Calculating measures such as mean, 
            median, mode, variance, and standard deviation.
            
    •   Distribution Analysis
        Understanding how data values are distributed using histograms 
        and density plots.

    •   Correlation Analysis
        Measuring relationships between variables using 
            correlation coefficients and heatmaps.

    •   Outlier Detection
        Detecting unusual observations that differ significantly 
        from the rest of the data.

    •   Grouping and Aggregation
        Summarizing data by categories, groups, or segments.

    •   Trend Analysis
        Identifying patterns and changes in data over time.

--- s:  [2.6.3] Data Visualization

+   Data Visualization
    ~ is the graphical representation of data using 
        charts, graphs, and plots. 
    It helps analysts and decision-makers understand
        complex information quickly and effectively.

+   Benefits of Data Visualization
    *   Simplifies large datasets.
    *   Identifies trends and patterns easily.
    *   Detects anomalies and outliers.
    *   Improves communication of insights.
    *   Supports better decision-making.


+   Common Visualization Techniques

    •   Bar Chart: 
        A bar chart uses rectangular bars to compare values across 
            different categories. 
            The length or height of each bar represents the magnitude 
            of the corresponding value.
        Use: Category comparison, 
            ranking products, and performance analysis.
        Example: Comparing sales of laptops, 
            smartphones, and tablets in a retail store.

    •   Pie Chart: 
        A pie chart represents data as slices of a circle, 
            where each slice shows the proportion of a category 
        relative to the whole.
        Use: 
            Showing percentage distribution and composition of data.
        Example: 
            Displaying the market share of different smartphone brands.

    •   Line Chart: 
        A line chart connects data points using lines to 
            show trends and changes over time.
        Use: 
            Trend analysis, forecasting, and time-series data visualization.
        Example: 
            Monitoring monthly revenue growth of a company throughout the year.

    •   Area Plot: 
        An area plot is similar to a line chart but fills the 
            area beneath the line, 
            emphasizing the magnitude of change over time.
        Use: 
            Visualizing growth, cumulative totals, and trends.
        Example: 
            Showing cumulative website traffic across several months.


    •   Histogram: 
        A histogram groups numerical data into intervals (bins) and 
            displays the frequency of observations in each interval.
        Use: Understanding data distribution, spread, and skewness.
        Example: 
            Analyzing the distribution of student examination scores.

    •   Scatter Plot: 
        A scatter plot displays individual data points to reveal 
            relationships between two numerical variables.
        Use: 
            Correlation analysis, trend identification, and 
                outlier detection.
        Example: 
            Examining the relationship between advertising expenditure 
            and sales revenue.

    •   Box Plot: 
        Box Plot: 
            A box plot summarizes the distribution of data using quartiles 
            and highlights outliers.
        Use: 
            Detecting outliers and understanding data spread.
        Example: 
            Comparing salary distributions across different departments.

    •   Heat Map: 
        A heat map uses colors to represent data values or 
            correlation strengths between variables.
        Use: Correlation analysis and pattern identification.
        Example: 
            Visualizing correlations among features in a 
            machine learning dataset.
