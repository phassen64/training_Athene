Fragen zu dieser Aufgabe
Worin besteht in VS Code der Unterschied 
	zwischen dem User und System Installer?
	
<<<	 
a)	Die Benutzerinstallation von VS Code wird normalerweise 
	in einem Ordner im Benutzerverzeichnis installiert. 
Dies bedeutet, dass sie nur für den angemeldeten Benutzer 
	auf dem Computer verfügbar ist und 
keine Systemberechtigungen erfordert. 
Keine Administratorrechte erforderlich.
b) Die Systeminstallation von VS Code wird normalerweise 
	im systemweiten Installationsverzeichnis 
(z. B. unter "Programme" auf Windows) installiert. 
Dies macht sie für alle Benutzer auf dem Computer verfügbar. 
Administratorrechte erforderlich.
